# 招聘测评管理端

## 启动

先确保后端已在 `http://localhost:8080` 启动，然后在本目录执行：

```powershell
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。开发服务器会把 `/api` 请求代理到后端 `8080` 端口。

## IDEA 启动

用 IDEA 打开 `frontend` 目录，在内置 Terminal 执行上面的两个命令即可。也可以建立一个 npm Run Configuration：

- package.json：选择当前目录的 `package.json`
- Command：`run`
- Scripts：`dev`

当前页面已实现管理员/HR 登录、任务统计、任务列表筛选分页、详情查看、撤回、延期和归档。

创建测评任务时无需选择评估人员。候选人提交后，HR 在任务详情确认答案，再分配评估人员；评估人员打开详情不会自动开始评估，必须明确点击“开始评估”。

模板管理页面支持：

- 新建模板并配置文本题、单选题、多选题和文件上传题
- 查看并选择任意模板版本生成新草稿
- 发布草稿或历史版本，并删除未发布、未被任务引用的版本
- HR 创建草稿模板
- HR_MANAGER 或 ADMIN 发布模板版本

任务详情支持重新生成候选人测试链接。新链接生成后旧链接立即失效，新链接只在弹窗中返回一次。

评估人员工作台使用独立路径：

```text
http://localhost:5173/review
```

评估人员登录后可以查看本人待办、阅读答案和附件，并提交“通过”“不通过”或“保留”结论。不通过时必须填写原因，当前不涉及评分。

候选人测评链接使用 `/assessment/{token}` 路由，打开有效链接后直接进入测评，支持动态题目、自动保存草稿、附件上传和最终提交。候选人手机号在管理端创建任务时必填，不参与测评入口验证。
